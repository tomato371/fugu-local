## 採点を4段階に分解する

| 段階 | 判定 |
|---|---|
| `exact` | `got` と `expected` が文字列として完全一致 |
| `normalized` | `normalize_answer()` を通すと一致（表記ゆれの救済） |
| `equivalent` | さらに `Fraction` / `math_verify` で数学的に同値 |
| `wrong` | どれでも一致しない |

**厳密採点 = `exact` のみ。寛容採点 = `equivalent` まで許す（現行）。**
fugu と Fable を同じ手続きで採点し、**IDの積集合**だけで比較する。

### 差は全部 MATH-500 にある

math500 以外の5データセットは、fugu も Fable も **厳密 = 寛容** で、救済が1問も効いていない。
つまり -9 は math500 の答案表記だけで生じている。

- fugu: 50問中 **18問**が厳密で落ちる（うち**誤答は1問だけ**、17問は書式）
- Fable: 50問中 **9問**が厳密で落ちる（うち誤答1問、8問は書式）

厳密採点は**双方を罰する**。差は「fuguの答案表記がFableより汚い」ことに帰着し、
**実力差ではない。**

### fugu が書式で落としている17問の内訳

| 種類 | 件数 | 例 |
|---|---:|---|
| 素の分数を LaTeX にしていない | 5 | `-35/9` ← `-\frac{35}{9}` |
| 度記号の欠落 | 3 | `30` ← `30^\circ` |
| `\dfrac` を使っている | 2 | `\dfrac{\pi}{6}` ← `-\frac{\pi}{6}` |
| 空白の有無 | 2 | `-13x + 3` ← `-13x+3` |
| ASCII 表記 | 1 | `-sqrt(3)` ← `-\sqrt{3}` |
| 小数で答えている | 1 | `0.09` ← `\frac{9}{100}` |
| 変数宣言の欠落 | 1 | `[-2,7]` ← `x \in [-2,7]` |
| 桁区切り | 1 | `11111111100` ← `11,\! 111,\! 111,\! 100` |
| 選択肢の書式 | 1 | `C` ← `\text{(C)}` |

## 対処: `fugu_canonical.canonicalize_math_answer()`

**採点器は触っていない。**直したのは出力側である。

- `expected` を一切見ない（引数は自分の出力だけ。テストでシグネチャを固定）
- 値を変えない。表記だけを揃える
- 投票そのものには手を入れていない。**票は値について、報告は形式についてであり別の話**

変換するもの: `\dfrac`/`\tfrac` → `\frac` ／ `a/b` → `\frac{a}{b}` ／
`sqrt(x)` → `\sqrt{x}` ／ 有限小数 → 既約分数。

変換しないもの（誤変換の危険が大きい）: 度記号の付与・桁区切り・選択肢の `\text{}` 化・空白の増減。

### 効果（記録済みデータで実測）

**8問を救済。math500 の厳密が 32/50 → 40/50、fugu 全体で 182 → 190。**
Fable の 191 まであと1問。

## 残りをどこまで詰められるか

### 原理的に取れないものがある

**参照解答（MATH-500）側の表記が統一されていない。**

- `\frac{...}` を使う問題と `\dfrac{17}{50}` を使う問題が混在している
- `-13x+3`（空白なし）と `288 \pi`（空白あり）が混在している

したがって**厳密完全一致で満点を狙うのは不可能**であり、
現実的な目標は「Fable と同等」であって「全問一致」ではない。

### プロンプト側で取れる見込みのもの（未検証）

度記号3問・変数宣言1問・選択肢書式1問は、
「問われた形式のまま答える」よう指示すれば取れる可能性がある（**+3〜5問の見込み**）。
ただし**これは再計測しないと確認できない**。本監査では実装していない。

## 環境についての注意

`math_verify` が入っていない環境で `answers_equivalent` を呼ぶと、
例外が握り潰されて `False` になり、**寛容採点が3問ぶん過少に出る**（199 → 196）。
本監査は `math_verify` を導入したうえで測っている。再現時は必ず入れること。
