03

予算の逆進性——計算は落とす問題に注がれている

基準構成 sc@nim の 90 問を、1 問ごとの消費リクエストで層別する。 多数決が割れると自動で追加サンプリングが走るため、消費量は「その問題の難しさ」の代理変数になる。

消費リクエスト帯 別の正答率

sc@nim・AIME 90問。棒の上の数字は各帯の問題数。

票が収束した帯 上限（20票）まで割れ続けた帯

正解した問題と落とした問題の消費量

単位が異なるため 2 枚に分けた。左＝リクエスト数、右＝壁時計秒。いずれも中央値。

これが最も実務的な発見だと思う。 落とした 15 問は、正解した 75 問の 4.0 倍のリクエストと 3.1 倍の時間を消費している。

票が割れる → 追加サンプリング → また割れる、というループが、解けない問題にこそ予算を集中させている。40〜60 リクエスト帯が正答率 100%・中央 159 秒で最も安く正確なのに対し、100 リクエストを超えた問題群は 23 問中 11 問しか当たらない。

つまり SC_MAX=20 の追加サンプリングは、後半ほど期待値が下がる投資になっている。100 リクエストを超えた時点で打ち切り、その予算を別の手（戦略層化・対審）に回すほうが合理的である可能性が高い。

ケーススタディ：aime26-15

5 構成が連続で落とし、6 番目で解けた 1 問。計算量スケーリングの限界と、設計変更が効く理由が、 1 問の中に凝縮されている。

aime26-15 の攻略履歴

正解 83。sc@nim から sc6@nim まで 5 構成が失敗し、sc7@nim が 47 リクエストで正解に到達した。

sc@nim  3系統・20票上限 sc2@nim  同左・再測定 sc3@nim  4系統・32票・思考32k sc4@nim  + DeepConf 自信度加重 sc6@nim  + SC-Court 対審 sc7@nim  + S3C 戦略層化 → 83 ✓

sc3 は票数を 32 まで積み、思考を 32k トークンから始めた。それでも解けなかった。 sc7 が投じたのは 47 リクエスト・4,563 秒——sc3 の 1/3 以下である。

違いは量ではなく多様性の作り方にある。S3C（戦略層化）は解く前に強モデルへ 「本質的に異なる攻め方」を列挙させ、各サンプルにラウンドロビンで強制割当する。 実装は [Strategy directive: solve using this approach and no other: …] をプロンプトに注入するだけの短いコードだ。

温度 0.7 で 32 回サンプリングしても、全系統が同じ筋読みをしていれば票は同じ誤りに揃う。 多数決は確率的な誤りしか直せず、相関した誤りは増幅する。 sc3 が失敗し sc7 が成功したことは、この問題の誤りが確率的ではなく系統的だったことの直接証拠になっている。

06

この実測が示していること

1. 計算量スケーリングは 93% 付近で飽和した。 sc2 までで 93.3%。そこから票数を 32 へ、思考を 32k へ積んだ sc3〜sc5 は、2,445 リクエスト・約 34 時間で 1 問しか動かせなかった。test-time compute scaling の飽和点を、自宅で 0 円で実測したことになる。

2. 飽和の先を動かしたのは設計変更だった。 SC-Court（対審集約）と S3C（戦略層化）は、計算量ではなくサンプル間の誤り相関を壊しにいく手法で、387 リクエストで 2 問を救った。sc3 の 1/6 のコストである。

3. 予算配分が逆進的になっている。 落とす問題に 4 倍のリクエストが注がれている。「割れたら足す」という単純な追加ルールが、期待値の低い方向へ予算を送っている。

4. AIME26 で基準を超えた。 30/30 対 Fable 29/30。ただし n=30 であり、1 問は 3.3 ポイントに相当する。「勝った」ではなく「同水準に到達し、単価を 0 円に抑えた」が正確な主張になる。

この結果を外に出すときの主張の立て方

「Fable と同点」は n=30 では弱い。強いのは曲線そのものである。 同一設計・同一モデル群で、投じた計算量と到達精度の関係を 9 点測り、飽和点と、 飽和後に効く介入を特定した——これは個人で再現している例がほとんどない種類のデータだ。

加えて、否定的結果が残っていることに価値がある。DeepConf は正しく実装した上で 0/5 と測られ、コードには 【実測 2026-08-05: 0/5 で有害と結論。記録用に構成は残す】 と書かれたまま保存されている。異種混成モデルでは信頼度スケールが揃わない、という知見である。

残っている穴

sc8・sc9 の ∞ は「効かなかった」ではなく「まだ 1 問ずつしか試していない」。 残り 3 問は 5〜8 構成が連続で落とした最難問であり、ここでの試行数不足は結論を出すには早い。 また GPQA は rc=1 で失敗したまま（2026-08-04 05:00）で、理数系の難関ベンチが欠けている。
